# Troubleshooting

| Problem | Fix |
|---|---|
| *Allocation on device 0 would exceed allowed memory* during sampling | Video memory too small for that size. Turn **FFN chunking** on, or lower megapixels. **Restart ComfyUI after any out-of-memory error** (a run right after one produced broken NaN frames). |
| Out of memory at *Decode latent to frames*, after sampling finished | Restart ComfyUI, then lower **megapixels** or turn **FFN chunking** on. The workflows decode in one pass: a tiled decode splits the clip into frame windows, and each window comes out a little brighter or darker, which shows as a brightness jump mid-clip. |
| Painter workflows: *Color Drift Fix: the video contains broken (NaN) frames* (older copies: *linalg.eigh … failed to converge* at *Match colors to start image*), or the video comes out black | Broken (NaN) frames from the sampler, not a color problem: with a black clip the colors cannot be fitted, and *Seamless Loop* reports the same NaN. Seen at **motion amplitude** 1.3 on one seed (same seed fine at 1.15, and fine with the plain Wan node). Change the seed or lower the amplitude to 1.15. |
| *Seamless Loop input contains NaN or infinity* | Broken frames, usually right after an out-of-memory error. Restart ComfyUI and run again. If it repeats in a fresh session, remove `--fast fp16_accumulation`. |
| Crash: *Windows fatal exception: access violation* while loading a model | Out of memory. Restart ComfyUI before rendering, enlarge the page file, don't use `--disable-dynamic-vram`. |
| Loop "flashes" white at the loop point, or the end has a different tone from the start | Keep **color drift fix** on (1) and the **Seamless Loop** node active; keep duration at 5 s (16 fps). With RTX upscale on, keep *Keep colors after RTX* in the Upscale group. |
| I2V or Loop: later frames drift in color away from the start image | Keep **color drift fix** at 1. If an I2V or Loop workflow still has *Match colors to start image* (Transfer Color), it is an old copy: load the current one from [`workflows/`](../workflows). (The Long workflows keep *Match colors to start image* on purpose; see [settings](settings.md).) |
| Mouth keeps moving | Prompt for closed, still lips; turn **negative** on. If it still moves, also turn on *Switch: NAG (low)* inside the subgraph. |
| The clip cross-fades or morphs into the end image | The end image is too different from the start image (framing, size in frame, background, outfit or style), or the prompt does not describe the motion between the two poses. Use an end image from the same character sheet or render, and describe the move in the prompt. Set **end image** to *none* to turn it off. |
| Console shows *ConnectionResetError: [WinError 10054]* / `_call_connection_lost` | Harmless. ComfyUI logs this when the browser tab closes or refreshes and the websocket drops before the server shuts the socket down. The run is unaffected and the output is saved. **mines-pack** hides this one traceback (restart ComfyUI after installing or updating it); other errors are still shown. Tracked upstream in [Comfy-Org/ComfyUI#15163](https://github.com/Comfy-Org/ComfyUI/issues/15163). |
| Ref2VA: first run is very slow, or out of memory | The H3 model plus text encoder are about 28 GB; on 32 GB of RAM it relies on the page file (enlarge it). Turn **FFN chunking** on or lower megapixels, then restart ComfyUI. |
| Red "missing node" boxes | Install the custom node pack from the [install guide](install.md) and restart. |
| Missing `MinesLoadImageOptional`, `MinesSVIProEndFrame`, `MinesColorDriftFix` or `MinesKeepSourceColors` | Install [mines-pack](https://github.com/kuromatcha/mines-pack) (`git clone` into `ComfyUI/custom_nodes/`) and restart ComfyUI. |
| Missing `DaSiWaLoadImageOptional` or `DaSiWaSVIProEndFrame` | The workflow was saved before these nodes moved to mines-pack and were renamed. Load the current workflow from [`workflows/`](../workflows) instead, and delete any old `ComfyUI-DaSiWa-EndFrame` folder from `ComfyUI/custom_nodes/`. |
| NVFP4 workflow errors or is slow | Needs an RTX 50-series GPU and PyTorch built for CUDA 13. The GGUF workflows for other cards were dropped; an older version of this repository still has them. |
| Model files missing in dropdowns | Check the folders in the [install guide](install.md), then press **R** in ComfyUI or restart it. |
